📚 Exam Buddy AI
📖 Overview

Exam Buddy AI is an AI-powered study assistant designed to help students prepare for exams more efficiently. 
It provides instant explanations, generates quizzes, summarizes notes, creates personalized study plans, and motivates students throughout their learning journey.
The app solves a common problem faced by students: spending too much time searching for study material and organizing exam preparation. Exam Buddy AI brings multiple study tools together in one easy-to-use application.

🌍 Live Demo

Live Application:

https://exam-buddy-two.vercel.app/

💡 Problem It Solves

Many students struggle with:

Understanding difficult concepts.
Creating study schedules.
Revising lengthy notes.
Testing their knowledge before exams.
Staying motivated while studying.

Exam Buddy AI helps students learn faster and prepare more effectively using Artificial Intelligence.

✨ Features

🤖 AI Chat Assistant for answering study questions.

📝 Quiz Generator for creating practice quizzes.

📄 Notes Summarizer to convert long notes into concise summaries.

📅 Study Planner to generate personalized study schedules.

💪 Daily Motivation to encourage consistent learning.

🔐 User Login and Sign Up system.

📱 Responsive design for desktop and mobile devices.


🤖 AI Feature


The application uses Google Gemini AI through a secure backend service.

The AI assistant is instructed to:

Explain concepts in simple language.

Generate educational quizzes.

Summarize notes accurately.

Create realistic study plans.

Motivate students during exam preparation.

Focus on educational content and student learning.
